# Rural UP Brand System

## Type

- Display: self-hosted Fraunces (`RuDisplay`) for editorial headings and named stays.
- UI: self-hosted Manrope (`RuSans`) for navigation, controls, prices, forms and body copy.
- System fallback remains only for unavailable glyphs, including future Hindi support.

## Icons

`themes/rural-up-theme/img/rural-up-icons.svg` is the shared 24px, `currentColor`, 1.8px-stroke icon system. Use it for customer-facing Rural UP controls. Legacy Font Awesome remains loaded only where hidden QloApps/module runtime behavior still references it; it is not the visible shell icon system.

## Provider Exceptions

- Payment gateway logos and hosted payment controls retain their trademarked imagery.
- Existing provider-generated internal icons may remain until their templates are explicitly replaced, but must be wrapped in Rural UP typography and spacing.
