## Idea
Polish mobile experience of the Rural UP theme. Verified issues via Playwright measurements at 375px and 1440px against live localhost:8081: (1) homepage hero search panel is hidden on mobile by bootstrap 'hidden-xs' in themes/rural-up-theme/modules/wkroomsearchblock/views/templates/hook/landingPageSearch.tpl line 8, leaving only a 'Search stays' pill (landingPageXsBtn.tpl via hookDisplayAfterHeaderHotelDesc) whose tap reveals a raw unstyled table's display:table form oddly; (2) two menu buttons render on mobile — the working module hamburger ('.header-top-menu .nav_toggle', opens #menu_cont) plus a broken duplicate 'a.ru-mobile-nav' linking to '#footer' (dead anchor) in header.tpl line 121 with its own CSS; (3) the #menu_cont slide-in panel (module default navigationMenuBlock.tpl + blocknavigation.css) is cheap: 50x50 blue/green close box whose icon-close glyph renders empty (X appears as blank box at top-right, reported misplaced), unstyled link list; needs redesign per Rural UP design template (cream panel, serif brand row, aligned X with SVG icon, spaced nav links); (4) search results page (category id_category=21) severely misformatted at ALL viewports: a 1609px-tall '.fh-rating-strip' rendered in the left column because categoryPageSearch.tpl calls {hook h='displayFhHotelRating' id_hotel=$id_hotel|default:0} with no hotel; the fh-ic star CSS + '#fh-ic-star' SVG sprite are completely missing (stars render as default 300x150 empty SVGs), pushing the toolbar/results ~365px down on desktop; on mobile the bootstrap row/col negative margins also produce 405px horizontal overflow (bodyScrollW 405 vs 375). Also mobile: hero padding (48px 0 294px) and absolute bottom:-180px search container + #index columns-container padding-top:188px were tuned for the hidden panel and need rebalancing once the panel becomes visible in-flow; must keep the working .ru-mobile-search-toggle expand behavior and #category occupancy bottom-sheet on mobile. Plan fixes in theme only (no module/core file edits where avoidable).

## Implementation
- Remove dead duplicate menu button: delete the <a class="ru-mobile-nav" href="#footer"> anchor from themes/rural-up-theme/header.tpl and strip its CSS rules (.ru-mobile-nav block incl. the @media(max-width:767px) display rule) from css/rural-up.css so the only menu button is the module nav_toggle hamburger.
- Show hero search on mobile: remove bootstrap 'hidden-xs' from the container in modules/wkroomsearchblock/views/templates/hook/landingPageSearch.tpl; remove the redundant 'Search stays' pill by deleting the {hook h="displayAfterHeaderHotelDesc"} block from themes/rural-up-theme/modules/hotelreservationsystem/views/templates/hook/headerHotelDescBlock.tpl; hide .fh-mobile-search-btn via CSS as a safety net.
- Rebalance mobile homepage hero: in css/rural-up.css mobile block make .header-rmsearch-container static (position:static, bottom:auto) on index, shrink .ru-hero bottom padding, drop the #index columns-container padding-top:188px override so the visible in-flow search panel sits under the hero copy cleanly on <768px; desktop layout untouched.
- Redesign the slide-in menu: add theme override themes/rural-up-theme/modules/blocknavigationmenu/views/templates/hook/navigationMenuBlock.tpl keeping the exact JS contract (.nav_toggle, #menu_cont, .menu_cont_left/right toggles, .close_navbar, .navigation-link, $navigation_links loop, displayDefaultNavigationHook/displayExternalNavigationHook blocks) with a Rural UP sheet: flex header row with serif 'Rural UP' brand + proper X button using the ru-icon-close SVG sprite aligned top-right, eyebrow 'Explore', large serif spaced nav links with hairline separators, footer help link.
- Style the new menu in css/rural-up.css: cream/paper full-height right sheet (replace generic #menu_cont rules), X button 40px with ink stroke icon and hover, link typography RuDisplay 23px, keep transition/slide from blocknavigation.css or re-specify, ensure no overlap with .close_navbar legacy styles.
- Fix category/results page mess: in themes/rural-up-theme/modules/wkroomsearchblock/views/templates/hook/categoryPageSearch.tpl only call {hook h='displayFhHotelRating'} when a hotel id is set ({if $id_hotel|intval}) so the 1609px strip disappears from category pages.
- Restore the star component globally: add .fh-ic/.fh-ic--star-sm sizing and .fh-stars positional overlay fill CSS (--fh-score based) to css/rural-up.css, and inject the missing inline SVG sprite <symbol id="fh-ic-star"> once in footer.tpl so rating strips/badges render correctly on product pages and anywhere else the component is used.
- Kill horizontal overflow on mobile results: in css/rural-up.css mobile block reset #category #columns row/col margins and left/right column paddings so bodyScrollW equals 375 (currently 405px) without disturbing the desktop 3-column grid or the Modify-search toggle / occupancy bottom sheet.
- Verify at 375px and 1440px with system Chrome + Playwright (host): homepage shows hero search panel with no second menu button; menu opens with redesigned X at top-right; category URL loads with toolbar directly after the Modify search panel, no horizontal scroll, cards full-width; then rebuild the theme CSS/template cache in the container (already bound-mounted via docker-compose.dev.yml) and re-run the measurement script.
- Regression check navigation: homepage hero copy/panel spacing, desktop header/menu panel appearance, header top menu links (Our Properties), region page, and product page rating strip rendering; clear smarty/compile cache afterward.
