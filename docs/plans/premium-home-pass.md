## Idea
Elevate the farmhouse QloApps child theme (themes/my-farmhouse-child-theme/) from functional-but-"cheap" to a premium, Booking.com-grade booking experience on the homepage and shared components, using competitor research (Booking.com, Airbnb, MakeMyTrip, Agoda, Expedia) as the design evidence base. Core deliverable 1: record the research in a new docs/RESEARCH-COMPETITORS.md (findings + source URLs + icon-set/media licensing notes). Core deliverable 2: restyle the homepage search panel (currently a 6-column grid of separate boxed fields with 12px uppercase labels + chip row — reads as a dashboard form) into a Booking-style single horizontal white bar: segments separated by hairline dividers, small labels above values, tinted field fills, one integrated pill CTA, trust line under the bar. CRITICAL INVARIANT: preserve every wkroomsearchblock field id/name (hotel_location, location_category_id, check_in_date, check_out_date, adult_count, child_count, number_of_rooms, search_room_submit), CSS classes (header-rmsearch-input, input-date, daterange_value_from/to, guest_occupancy, occupancy[] inputs), hooks (displaySearchFormFieldsBefore/After) and JS contracts (datepicker on .input-date, Bootstrap data-toggle dropdown on guest_occupancy, autocomplete on #hotel_location) — the restyle must be CSS-only where possible. Core deliverable 3: integrate the panel into the hero the way Booking does (panel overlapping the image, not floating under the header), scale up hero typography with clamp(), add a trust/eyebrow line. Core deliverable 4: premium icon system — pick one self-hosted MIT stroke icon set (recommend Tabler or Lucide, 24px grid 2px stroke), replace the mixed FontAwesome icons in the trust strip/nav/footer with a consistent SVG sprite, keep total added weight tiny (<15KB gz). Core deliverable 5: royalty-free media pass — curate a small set of Unsplash/Pexels farmhouse/rural-UP images (commercial-use licensed, no model-release risk: avoid recognizable faces), update WK_HOTEL_HEADER_IMAGE + hero copy in DB config, document the swap; keep demo images as fallback. Core deliverable 6: shared-component premium polish (buttons pill + hover lift, consistent card radius/shadow, focus rings, typography scale, whitespace rhythm) and efficiency (no new JS, transform/opacity-only motion, self-hosted fonts, lazy-loaded images, weight audit). Verification: Playwright at 375/768/1440 — no horizontal overflow, touch targets >=44px, no console errors; full search-flow regression (home → category → product → cart) confirming hooks/selectors/JS contracts intact; before/after screenshots; clear smarty caches; atomic conventional commits on feature/rural-marketplace-alpha; update docs. Non-goals: no backend/DB schema changes beyond config value updates (WK_* copy/hero image), no new hooks, no activities section (deferred), no module logic changes.

## Implementation
- Create docs/RESEARCH-COMPETITORS.md: competitor search-widget patterns (Booking.com single-bar segments w/ hairline dividers + grouped date range + occupancy counter + trust line; Airbnb pill segments + circular brand CTA; MMT/Agoda/Expedia same 4-field schema; A/B evidence from GoodUI/Baymard), 'cheap vs premium' heuristics (grouped controls, whitespace, one accent palette, consistent radii/shadows, micro-interactions), icon-set comparison table (Lucide ISC / Tabler MIT / Phosphor MIT, 24px 2px stroke, self-host SVG sprite), royalty-free media licensing notes (Unsplash/Pexels commercial OK, no attribution required, avoid recognizable faces w/o model releases), each with source URLs, and a mapping to our constraints (field/JS contract preservation).
- Restyle the homepage search panel to a Booking-style single bar (CSS-only in css/components.css): .fh-search-grid becomes one rounded container (radius lg, soft layered shadow) with zero gaps; each field segment gets hairline dividers (border-left/::after inset), small label above value (drop uppercase 12px -> sentence-case 13px muted), tinted fill (#f5f5f5-ish token) on hover/focus with 2px primary focus ring; occupancy trigger shows '2 adults · 1 room' summary; integrated pill CTA (primary) at the right end; quick-date chips collapse to a slim row under the bar (desktop) / stacked full-width fields (mobile, incl. the fancybox #xs_room_search_form modal). Preserve 100% of field ids/names/classes/hooks and the datepicker + Bootstrap dropdown JS contracts; verify via DOM diff that searchForm.tpl is untouched unless a wrapper class is needed.
- Hero + panel integration (Booking-style overlap): adjust #index .fh-hero margin-top/panel positioning so the bar overlaps the hero image lower third instead of hugging the translucent header; hero title scale-up with clamp() (40px -> clamp(40px, 5.5vw, 64px)), tighter letter-spacing for Fraunces, stronger bottom gradient for text legibility, optional small eyebrow line above the title (WK_* config copy); add the trust line ('Free cancellation · Direct booking · No hidden fees') under the search bar on the homepage; keep the header transparent-over-hero behaviour; mobile keeps stacked panel + existing pill.
- Premium icon system: add a self-hosted MIT stroke icon subset as an inline SVG sprite (recommend Tabler or Lucide, 24x24, 2px stroke, currentColor) — ~20-30 icons max (search, calendar, users, bed, leaf, home, phone, shield-check, tag, location-pin, chevron, close, menu, star, wifi, heart, clock, rupee, check, arrow-right) under themes/my-farmhouse-child-theme/icons/ or as a CSS mask/background layer; replace mixed FontAwesome icons currently used in the trust strip, nav, footer, contact and 404 components with the consistent sprite; add the set's LICENSE file in the theme dir; verify total added payload < 15KB gz and no new external requests.
- Royalty-free media pass: inventory current images (hotel_header_image_1776418446.jpg 1200x784 stock demo, farmhouse-up-logo PNG, PS_LOGO/PS_FAVICON config); select a small curated set (4-8 images: hero, interiors, amenities, rooms, testimonials background) from Unsplash/Pexels suitable for rural UP farmhouse stays, licensed for commercial use, avoiding recognizable faces/model-release risk; download into the host img volume so it survives rebuild (entrypoint seeds from /usr/local/share/qloapps-media), update WK_HOTEL_HEADER_IMAGE + WK_TITLE/COPY_HEADER_BLOCK config values; keep demo images as fallback; add loading=lazy to below-fold images where templates allow; document the swap + image recommendations in the research doc.
- Shared-component premium polish (css/components.css + design-system.css tokens): unify button styles (pill radius, hover lift via transform translateY(-1px) + shadow, focus-visible rings), card radii/shadows consistency, form-control focus states, consistent 8px spacing rhythm, contrast fixes to WCAG AA (muted text >=4.5:1 on cream), typography refinements (body 16/26, section headings with Fraunces display, restrained letter-spacing); motion only on transform/opacity with reduced-motion guard; no new JS dependencies; audit total added CSS/JS weight and keep the farmhouse efficiency targets (added JS <25KB gz, CSS <30KB gz added on top of current).
- Mobile + efficiency verification: Playwright QA at 375/768/1440 on home/category/product — no horizontal overflow, touch targets >=44px, no console errors, search panel stacked correctly in fancybox modal; full search-flow regression: home search (datepicker + occupancy dropdown + quick chips) -> category results -> product booking form -> cart, confirming all preserved selectors/JS contracts still fire; measure page weight (document.transferSize + asset audit) before/after; capture before/after screenshots into /tmp/opencode; clear cache/smarty/compile + cache/smarty/cache.
- Document + commit: update docs/PROJECT-GUIDE.md (icon system, media source, new search-bar component conventions, research doc link) and docs/CLIENT-REQUIREMENTS.md (changelog entry for the premium pass + research file); commit atomically per surface with Conventional Commits on feature/rural-marketplace-alpha (feat(theme): ...), never main; final smoke test after commits (clear caches, verify homepage renders and search works).
