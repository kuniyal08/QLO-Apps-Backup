## Idea
Build the Rural UP stay-discovery platform on the farmhouse child theme, per the confirmed direction: CLEAN MODERN (Airbnb discipline), REFINED PALETTE (forest green #2F4A3C on cream #F7F4EF), TYPOGRAPHY-FIRST (design without photos — color-block surfaces, Fraunces display type leading), and scope = home + rooms + booking first, plus NEW discovery surfaces the client requires: REGIONS (managed module, seeded with ~6 UP regions: Bundelkhand, Awadh, Braj, Purvanchal, Rohilkhand, Kashi), ACTIVITIES (extend the existing ruralactivities module's surfaces — informational only, never in cart), and BLOG (new dedicated module with admin CRUD + seeded sample posts). English-first but i18n-ready (every string via translation methods per AGENTS.md). Discovery layer: region cards, activity chips, and stay+do bundles link into existing search/listing pages with pre-applied filters where the platform supports it — NO deep surgery on wkroomsearchblock. The site positions as the booking face of the UP government farm-stay initiative (Farm Stay investment drive Sept 2025, B&B/Homestay Policy 2025): trust-led, editorial voice, government-property friendly. CRITICAL INVARIANT (from Rural-Marketplace + farmhouse-frontend-redesign plans): preserve every QloApps/module hook, Smarty variable, field name, and JS contract for search -> availability -> room -> occupancy -> cart -> checkout -> confirmation; activities never enter inventory/cart/checkout/payment. Implements via modules (fhregions, fhblog) mirroring the ruralactivities pattern, theme template overrides, and per-page CSS/JS under themes/my-farmhouse-child-theme. Supersedes the photo-media work item of plan premium-home-pass (typography-first hero instead of curated Unsplash imagery); retains its icon-system and trust/conversion items. Verification: clear caches, Playwright QA at 375/768/1440 across ALL new + core pages, no horizontal overflow, 44px touch targets, no console errors, full booking regression, contract checklist, atomic conventional commits on feature/rural-marketplace-alpha, docs updated.
